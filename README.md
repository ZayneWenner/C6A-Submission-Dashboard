# C6A 提交数据仪表盘｜贾静文

把 EduSeed 平台上的**挑战定义**和**我的提交记录**变成一块能自己更新的看板，回答三个问题：还差多少、哪些要返工、哪些根本没开工。

## 目录结构

```
c6a-package/
├── 贾静文_C6A_仪表盘/       # 零依赖看板，双击 index.html 即可打开
│   ├── index.html           # 5 个视图，哈希路由
│   └── assets/              # app.js / data.js / styles.css
├── 贾静文_C6A_data/         # 数据管道：3 个脚本 + 中间产物 + Excel 总表
├── 贾静文_C6A_demo/         # 5 张真实运行截图 + DOM 校验 + 说明
└── 贾静文_C6A_AI日志.md     # AI 协作过程与三次真实返工
```

## 怎么看

| 想看什么 | 打开 |
|----------|------|

| 数据怎么来的 | `贾静文_C6A_data/README.md` |

## 五个视图

1. **总览** — KPI、完成率、状态分布、洞察结论
2. **挑战清单** — 20 个挑战，可按代号/状态筛选排序
3. **交付物校验** — 每个挑战的 required_deliverables 命中与缺失高亮
4. **时间线** — 10 条提交记录的时间序列
5. **口径与说明** — 数据来源、字段定义、公式、已知局限

## 数据可信性声明

- 所有数字来自脚本，**不手工填写**；换人换天按顺序重跑即可复现。
- 平台 API 为权威口径；本地扫描只用于"缺什么"的辅助提示，**不推翻平台状态**。
- 只包含本人的提交记录，是个人视角，不是班级口径。

## 复现方式

```bash
cd 贾静文_C6A_data
python scan_submissions.py   # 离线扫描本地交付物
python build_dataset.py      # 拉平台数据并合并（需校园网）
python build_excel.py        # 渲染 Excel 总表
```

再打开 `贾静文_C6A_仪表盘/index.html` 即可看到与新数据一致的看板。
